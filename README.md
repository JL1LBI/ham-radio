# ham-radio

アマチュア無線家向けの小さなツール（ミニアプリ）を置いている場所です。
*Small tools and mini-apps for amateur radio operators, by JL1LBI.*

## このリポジトリについて / About

私（JL1LBI）がアマチュア無線の運用のために作った、自作の小さなプログラムを公開しています。主に、VoIP無線（Peanut / WIRES-X / DMR）の運用を助けるTUIラッパー「FUNA Wrapper」シリーズと、シリアルポートまわりの小物ツールです。各ツールの詳しい説明や使い方は、それぞれのフォルダ内の README をご覧ください。

This repository hosts small, homebrew programs I wrote for my own amateur radio operation: the "FUNA Wrapper" series of TUI front-ends that help operate VoIP radio services (Peanut / WIRES-X / DMR), plus small utilities around serial ports. See the README inside each folder for details.

## 内容 / Contents

- **[FUNA Wrapper for Peanut](FUNA%20Wrapper%20for%20Peanut)** — Peanut を JP / GLOBAL の2つのマスターで同時に運用するためのTUIラッパー（Dual VFO）
  *A dual-VFO TUI wrapper for running Peanut on two masters (JP / GLOBAL) at once.*
- **[FUNA wrapper for WIRES-X](FUNA%20wrapper%20for%20WIRES-X)** — Yaesu WIRES-X のTUIフロントエンド（Dual VFO Edition）
  *A TUI front-end for Yaesu WIRES-X, Dual VFO Edition.*
- **[FUNA Wrapper for DMR Master](FUNA%20Wrapper%20for%20DMR%20Master)** — DMR向けのFUNA Wrapper
  *The FUNA Wrapper for DMR.*
- **[Serial Pin watcher](Serial%20Pin%20watcher)** — シリアルポートの信号ピンの状態を監視するツール
  *A small tool that watches the state of serial port signal pins.*
